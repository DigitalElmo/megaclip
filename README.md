# MegaClip

**[megaclip.games](https://megaclip.games)** — every new browser game worth playing, in one place. Miniclip energy for 2026.

MegaClip is a hand-picked list of 668 games you can play straight in a browser tab: indie games, .io multiplayer, AI-made games, fan ports, Pokémon fan games and daily puzzles. Click and play. Nothing to download or install. New games are added all the time.

It also has two big guides, all in the same search box:

- **[PC Ports](https://megaclip.games/decomps):** over 1,000 console classics that fans have rebuilt to run on PC, each linked to its own project page. Bring your own copy of the game.
- **[Pokémon Fan Games](https://megaclip.games/pokemon):** 3,893 Pokémon fan games and ROM hacks, each linked only to its official page (the maker's own site, forum thread, GitHub or itch.io).

That's more than 6,600 games in one search.

## How it works

MegaClip is a **list of links**. It's like a big bookmarks page.

- It hosts **no games** and **no game files**. Every game runs on its own maker's website.
- It has **no ads, no trackers, no cookies, no accounts and no logins**.
- The whole site is static HTML, built from [`games.json`](games.json), [`decomps.json`](decomps.json) and [`pokemon.json`](pokemon.json) by [`arcade.py`](arcade.py), [`pages.py`](pages.py) and [`pokemon_pages.py`](pokemon_pages.py). You can read every line of it here.

## Is it safe?

You can check it yourself instead of taking our word for it:

- **Security headers:** [Mozilla Observatory scan](https://developer.mozilla.org/en-US/observatory/analyze?host=megaclip.games) (A+). Strict Content Security Policy that allows only the page's own scripts (by hash), no framing, HTTPS only.
- **Google Safe Browsing:** [check megaclip.games](https://transparencyreport.google.com/safe-browsing/search?url=megaclip.games)
- **VirusTotal:** [scan megaclip.games](https://www.virustotal.com/gui/search/megaclip.games)
- **The code:** the page you visit is [`index.html`](index.html) in this repo, generated by [`arcade.py`](arcade.py). The headers it's served with are in [`vercel.json`](vercel.json).

Every game link opens in a new tab with `rel="noopener noreferrer"`, so the game's site can't touch the MegaClip tab.

## Suggest a game, or ask for a removal

Use the **Suggest a game** button on [megaclip.games](https://megaclip.games) or [open an issue](https://github.com/DigitalElmo/megaclip/issues/new/choose) with:

- the game's name and link
- whether you made it
- whether it works on a phone

**Made a game that's listed and want it changed or taken down?** Use the email button on [megaclip.games/about](https://megaclip.games/about) or open an issue and it'll be dealt with quickly. All games, names and trademarks belong to their owners.

## Build it yourself

```sh
python3 arcade.py       # rebuilds index.html, every game/category/PC Ports/Pokémon page, sitemap.xml and vercel.json
                        # (the generated game/, decomp/, pokemon/ and category/ pages aren't committed; this command makes them)
```

Thumbnails (`shots/`) aren't in this repo because they come from each game's own page. The build still works without them.

Each entry in `games.json` looks like this:

```json
{
  "name": "Game name",
  "url": "https://where-you-play-it",
  "host": "where-you-play-it",
  "cat": "indie",
  "note": "short tag",
  "mobile": "yes | no | maybe",
  "mobile_why": "why",
  "added": "2026-10-14",
  "img": "shots/....jpg"
}
```
